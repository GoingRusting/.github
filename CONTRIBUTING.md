# Contributing to GoingRusting

Thank you for taking an interest in these projects. Bug fixes, clear documentation, useful examples, and reproducible performance measurements all help.

## Choose a project

Start with the repository's README, open issues, and contribution guide. Its own setup instructions and contribution requirements take precedence over this shared guide.

For a large feature or architecture change, open an issue before implementing it. Describe the problem, the proposed approach, and any compatibility or performance tradeoffs.

## Small ways to start

- Follow the installation instructions and report a missing or confusing step.
- Improve an example or document a requirement you had to discover yourself.
- Reduce a bug to the smallest example that reproduces it.
- Check an existing issue against a current release and share your results.

## Bug reports

Search existing issues first. Include the project version or commit, your environment, reproduction steps, expected behavior, and actual behavior. For graphics or GPU problems, include the GPU and driver. Remove credentials and personal data from logs before posting them.

## Pull requests

1. Fork the relevant repository and make a focused branch.
2. Keep the change tied to one problem; link the related issue if there is one.
3. Follow that project's formatting, checks, and development instructions.
4. Update examples or documentation when behavior changes. Add regression coverage where it helps verify a fix.
5. Explain what changed and how you checked it. Include screenshots for visual changes.

For performance work, provide the workload, hardware, build settings, and before/after measurements. Include a reproducible procedure and explain any quality or correctness tradeoffs.

Check the destination repository's license and contribution terms before submitting. Only contribute code and assets you have the right to provide.

Please follow our [community conduct](https://github.com/GoingRusting/.github/blob/main/CODE_OF_CONDUCT.md). Questions about using a project belong in that project's issue tracker; see [support](https://github.com/GoingRusting/.github/blob/main/SUPPORT.md).
