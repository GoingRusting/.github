We explore how **Rust and GPU computing** can reshape game engines, machine learning, and real-time graphics. GoingRusting is home to independent projects built around that curiosity.

### Build with us

Bug reports, documentation fixes, reproducible benchmarks, and focused contributions are welcome. You can help by trying a quick start, reporting a confusing step, or sharing a small example.

- **Found a bug or have an idea?** Open an issue in the relevant project, with enough detail to reproduce the problem or understand the proposal.
- **Want to contribute?** Read the project's own contribution guide, or our [shared guide](https://github.com/GoingRusting/.github/blob/main/CONTRIBUTING.md) when one isn't provided.
- **Need help?** See [support](https://github.com/GoingRusting/.github/blob/main/SUPPORT.md) for where to ask.

Projects evolve independently. Check each repository for platform support, release notes, and license terms before using or redistributing it.
