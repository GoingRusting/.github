# GoingRusting community

This repository contains the [GoingRusting organization profile](https://github.com/GoingRusting), its visual assets, and shared community guidance.

## Explore the projects

- [RustingEngine](https://github.com/GoingRusting/RustingEngine) — Rust, Vulkan rendering, and hybrid CPU/GPU physics.
- [RustingBrain](https://github.com/GoingRusting/RustingBrain) — deep learning in Rust with CPU and GPU backends.
- [RustingShader](https://github.com/GoingRusting/RustingShader) — cinematic Minecraft graphics with Iris and GLSL.
